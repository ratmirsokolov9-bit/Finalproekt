## Описание проекта
Проект содержит автоматизированные тесты для проверки работы с базой данных и API сервиса заказов.

## Структура проекта

### SQL запросы
- query.sql` — Запрос для получения логинов курьеров с количеством заказов в доставке
- `query.sql2` — Запрос для получения статусов заказов по трекерам

### Автотесты
- `src/test/java/api/OrderApiTest.java` — Тест для автоматизации проверки API:
  1. Создание заказа
  2. Сохранение номера трека
  3. Получение заказа по треку
  4. Проверка кода ответа 200

### Документация
- `screenshots/test_execution.png` — Скриншот успешного выполнения теста
